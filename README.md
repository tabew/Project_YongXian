# Project YongXian

使用 Godot 开发的游戏项目。

## 环境

- Godot 4.7（Forward+ 渲染器）

## 目录结构

- `scenes/` — 场景文件
- `scripts/` — GDScript 脚本
- `assets/` — 美术、音频等资源
- `project.godot` — 项目配置
- `icon.svg` — 项目图标

## 运行

用 Godot 编辑器打开本目录（选择 `project.godot`），或在命令行运行：

```
godot --path .
```

导出模板、`.godot/` 缓存等已在 `.gitignore` 中忽略。
