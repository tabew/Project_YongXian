# Project YongXian

使用 **Godot 4.7** 开发的 2D 游戏项目。目前包含主菜单、**无限世界 + 区块流式加载 + 14 种生物群系**，以及一个可用 WASD 控制、带加速度的占位主角。

## 无限世界与区块加载

世界没有边界：地形只由 `(世界种子, 格子坐标)` 决定，**与区块划分无关**，所以任意区块都能独立生成，区块之间不会出现接缝，也不需要读取邻居数据。

| 概念 | 取值 |
|------|------|
| 格子 | 16 × 16 像素 |
| 区块 | 32 × 32 格 = 512 × 512 像素 |
| 加载半径 | 2 个区块 → 常驻 25 个区块 |
| 卸载半径 | 3 个区块（比加载半径大，留迟滞避免边界抖动） |
| 数据缓存 | 512 个区块（每块 2 KB，约 1 MB） |

区块的加载 / 卸载由 [chunk_manager.gd](scenes/world/chunk_manager.gd) 负责，只在玩家跨过区块边界时才重算要显示的范围。

### 性能设计

| 手段 | 说明 |
|------|------|
| 生成放工作线程 | 噪声采样是主要开销，丢给 `WorkerThreadPool`，主线程只负责铺格子 |
| 每线程一个生成器 | 每个工作线程各持一套 `FastNoiseLite`，避免多线程共用同一实例 |
| 每帧预算 | 提交生成、铺格子、回收区块各有上限，不会一口气卡住 |
| LRU 缓存 | 走回头路直接命中缓存，一次噪声都不重算 |
| 区块节点池化 | `TileMapLayer` 复用，卸载区块不销毁节点 |
| 格子坐标局部化 | 图层的节点位置承担世界偏移，格子坐标只用 `0..31`，四舍五入树不随玩家走远而膨胀 |
| 复用时不 `clear()` | 铺图总是写满 32 × 32 格，所以复用的图层不需要先清空 |
| 地图实例复刻 | 生成器实例可复刻 → 完全不依赖全局状态 |

### 实测数据（Godot 4.7，32 核）

```
区块数据生成    1.2 ms/块     ← 工作线程，不占主线程
铺进 TileMap     0.12 ms/块    ← 主线程

瞬时跨越 25 个区块（相当于瞬移）时，ChunkManager 的主线程开销：
  多线程生成   平均 0.120 ms/帧   最差 2.99 ms   超 4 ms 的帧 0/150
  单线程生成   平均 0.298 ms/帧   最差 6.70 ms   超 4 ms 的帧 6/150

正确性：
  sample_terrain 与已铺格子逐格比对   0 / 3072 不一致
  相邻区块交界两侧                   0 处接缝
  同种子不同生成器实例               完全一致
  回到原点                           25 个区块全部命中缓存，0 次重新生成
```

帧预算（16.7 ms）占用不到 2%，掉帧帧数为 0。

## 生物群系

群系由 **海拔 + 温度 + 湿度** 三套噪声共同决定：海拔先分出海洋 / 海岸 / 平原 / 山地 / 雪峰，平原再按温湿度细分。

| 群系 | 主要地形 | 群系 | 主要地形 |
|------|----------|------|----------|
| 深海 | 深水 | 沼泽 | 沼泽 |
| 海洋 | 浅水 / 浮冰 | 针叶林 | 针叶林 |
| 海岸 | 沙滩 | 苔原 | 苔原 |
| 沙漠 | 沙漠 | 雪原 | 雪原 |
| 稀树草原 | 稀树草原 | 山地 | 石地 / 山地 |
| 草原 | 草地 | 雪峰 | 雪峰 |
| 森林 | 森林 | 热带雨林 | 雨林 |
| | | | |

每个群系还配了「次要 / 点缀」两种地形，由一张高频 `variation` 噪声决定用哪一种，所以群系内部也有过渡，不会是一整块纯色。

**为什么需要对比度拉伸**：单纯形噪声的值几乎都挤在 0.5 附近，直接拿去判定的话，沙漠、雨林、雪峰这些需要极端温湿度的群系永远出不来。所以温湿度和海拔都过了一道 `_sharpen()` 把值往两端拉。

768 × 768 格范围内的实测分布：

| 群系 | 占比 | 群系 | 占比 |
|------|------|------|------|
| 海洋 + 深海 | 23.6% | 苔原 | 5.7% |
| 雪原 | 16.2% | 针叶林 | 5.2% |
| 森林 | 11.2% | 沼泽 | 5.0% |
| 草原 | 8.6% | 稀树草原 | 3.5% |
| 山地 | 7.4% | 沙漠 | 1.8% |
| 海岸 | 6.0% | 雪峰 | 0.3% |
| 热带雨林 | 5.7% | | |

## 主角移动

[scripts/player.gd](scripts/player.gd) 用 `move_toward` 做速度插值：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_speed` | 220 | 最大速度（像素/秒） |
| `acceleration` | 1400 | 按住方向键时每秒增加的速度 |
| `friction` | 1800 | 松开按键后每秒衰减的速度 |
| `collide_with_terrain` | true | 是否阻挡深水 / 浅水 / 山地 / 雪峰 |

按住方向键约 **0.16 秒**到达最大速度（每帧 +23.3），松开约 **0.12 秒**停下（每帧 −30）。位移按 X/Y 分轴推进，贴着海岸走不会卡住。

碰撞不查区块，而是直接问 `WorldGenerator` 这一格是什么地形——生成函数是纯的，所以判定结果和画面永远一致，也不用等区块加载完。查询结果按格子缓存，一帧最多算两次。

## 操作

| 按键 | 功能 |
|------|------|
| W A S D / 方向键 | 移动主角 |
| R | 换个种子重开世界 |

HUD 左上角显示种子、格子与区块坐标、当前地形与群系；右上角显示区块数量、生成与铺图耗时、缓存命中数、FPS。

## 快速开始

1. 用 **Godot 4.7+** 打开本目录（选择 `project.godot`）
2. 按 F5 运行，在主菜单点「开始游戏」
3. 或命令行运行：`godot --path .`

重新生成占位美术（可选，需要 Pillow）：

```
python tools/generate_art.py
```

`.godot/` 缓存、导出配置等已在 `.gitignore` 中忽略；`*.import` 与 `*.uid` 需要随资源一起提交。

## 已知限制

- **浮点精度**：主角世界坐标走到约百万像素之外后，位置精度会明显下降。真正的超远距离探索需要引入浮动原点（把已加载区块整体平移回原点附近）。
- **地形碰撞用代码判定**，没有走 TileSet 物理层；两者视觉上等价，但物理层能直接配合 `move_and_slide`。
